# AdGuard DNS API Client - Usage Guide

The AdGuard DNS API clients (.NET, TypeScript, Rust, PowerShell) moved to [`BloqrAI/bloqr-apiclients`](https://github.com/BloqrAI/bloqr-apiclients) and are no longer part of this repo.

For usage examples (authentication, devices, DNS servers, statistics, query logs, retry policies, and more), see that repo's documentation.

This repo (`bloqr-core`) now covers the rules compilers, shell scripts, PowerShell RulesCompiler toolkit, the Rust `rules-validator`, and the documentation site — see the [root README](../../README.md) and [docs index](../README.md) for what's here.
