# TypeScript API SDK Guide

The AdGuard DNS TypeScript API SDK moved to [`BloqrAI/bloqr-apiclients`](https://github.com/BloqrAI/bloqr-apiclients) and is no longer part of this repo.

For SDK usage (repositories, retry policies, pagination, rules-compiler integration, and more), see that repo's documentation.

This repo (`bloqr-core`) still hosts the TypeScript **rules compiler** (`@bloqr/compiler-core`, `src/adblock-compiler-core/`) — see the [TypeScript Rules Compiler guide](./typescript-rules-compiler.md) for that.
